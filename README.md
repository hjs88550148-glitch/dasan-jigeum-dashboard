# 덕자부동산 · 다산 지금지구 브리핑

Node.js 22 이상에서 `npm run build`로 `index.html`과 Worker를 빌드합니다. 로컬에서는 현재 셸에 `MOLIT_KEY`, `REB_KEY`를 설정한 뒤 `node preview.mjs`를 실행하고 http://127.0.0.1:4381/index.html 을 엽니다. 실거래와 가격지수는 로컬 서버를 통해 조회합니다. Sites 배포에서는 동일한 이름의 비밀 환경변수를 사용합니다.

- 국토교통부 아파트 매매 및 전월세 실거래 API 두 서비스의 활용 승인이 필요합니다. 순위는 계약일 기준 신고 건수로 계산합니다.
- 다산1동·다산2동 및 지금지구 필터는 단지명 목록 기반입니다. 다산동 전체는 공공 API의 법정동 값을 사용합니다.
- OpenStreetMap 단지명이 매칭되는 곳에 지도 핀을 표시합니다. 미매칭 단지는 지도 검색 링크를 표시합니다. 시설 거리는 지도 좌표의 직선거리입니다.
- 추천매물 4건은 브리핑용 예시입니다. 추가한 추천매물은 해당 브라우저에 저장됩니다.
