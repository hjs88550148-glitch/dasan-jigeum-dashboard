# 덕자부동산 · 다산 지금지구 부동산 대시보드

남양주시 다산동(지금지구·진건지구·도농 생활권) 아파트 실거래·시장지표·입지분석 브리핑용 대시보드.

## ★ 추천매물 바꾸는 법 (3단계)
1. 폴더의 **`start.bat`** 더블클릭 → 대시보드가 열립니다 (검은 창은 끄지 마세요)
2. 추천매물에서 **＋ 매물 추가** 또는 카드의 **✎ 수정** → 저장 (삭제도 수정 창에서)
3. **🌐 홈페이지에 반영** 버튼 클릭 → 1~2분 뒤 홈페이지에 반영 (안 바뀌어 보이면 Ctrl+F5)

홈페이지: https://hjs88550148-glitch.github.io/dasan-jigeum-dashboard/
버튼을 누를 때마다 최신 실거래·부동산원 지수도 함께 갱신되어 올라갑니다. 홈페이지(공개용)에서는 매물을 볼 수만 있고 고칠 수 없습니다.

## index.html (단일 파일 · 서버 불필요)
- `index.html`을 더블클릭하면 바로 열립니다. CSS·스크립트·로고·데이터가 모두 한 파일에 들어 있습니다.
- **index.html** — API 키 없음. 깃허브·외부 공유용. 만든 날짜 기준 실거래(최근 25개월)·부동산원 지수 내장본을 사용합니다.
- **index-live.html** — API 키 포함, 내 PC 전용(깃허브에 올라가지 않음). 열 때마다 최근 2개월 실거래를 공공데이터포털에서 실시간 갱신합니다.
- 두 파일 모두 `build-index.bat` 더블클릭으로 다시 만듭니다(약 1분). 부동산원 지수 갱신을 위해 매주 실행을 권장합니다.
- 추천매물 수정은 위 3단계(start.bat → 수정 → 홈페이지에 반영)로 하세요. index.html 파일 자체는 보기 전용입니다.

## API 키 설정 (처음 한 번)
`config.example.json`을 `config.json`으로 복사하고 공공데이터포털 키(`dataGoKrKey`)와 한국부동산원 R-ONE 키(`rebKey`)를 넣으세요. `config.json`은 .gitignore 대상이라 깃허브에 올라가지 않습니다.

## 서버 버전 실행
- `start.bat` 더블클릭 → 브라우저에서 http://localhost:8787 자동 열림
- 또는 터미널: `node server.mjs` (Node.js 18 이상, 별도 설치 패키지 없음)
- 처음 실행 시 최근 13개월 실거래를 받아 `cache/`에 저장 (약 30초~1분). 이후에는 빠르게 열립니다.

## 수정할 수 있는 파일
- `config.json` — API 키, 포트, 상호·전화번호 (깃허브 미포함, `config.example.json` 참고)
- `data/listings.json` — 추천매물 (화면에서 추가·수정해도 이 파일에 저장)
- `data/development.json` — 주변 개발계획 문구·출처
- `data/apartments.json` — 단지 좌표, 행정동(`hdong`), 생활권(`district`), 공공임대 여부(`rental`)
  - 행정동은 OpenStreetMap 경계 기준으로 자동 분류했습니다. 실제와 다른 단지가 있으면 `hdong` 값을 고치면 됩니다.
- `public/logo.svg` — 로고

## 참고
- 실거래는 계약 후 30일 이내 신고 → 최근 1~4주 자료는 늘어날 수 있습니다. 월간 기본값은 전월입니다.
- 평당가는 전용면적 3.3㎡ 기준입니다. 학군은 거리 기준이며 실제 배정은 학구도를 확인하세요.
- `config.json`, `index-live.html`에는 API 키가 들어 있으니 외부에 공유하지 마세요.
